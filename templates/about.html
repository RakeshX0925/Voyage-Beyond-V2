THE PROJECT BEHIND THE JOURNEY

About Voyage Beyond

A space-learning website upgraded into a Python-powered astronomy data exploration project.

✦

OUR PURPOSE

Learn about the cosmos. Explore the evidence.

Voyage Beyond brings together space education and practical data analysis. The original website's Home, About, Gallery, Quiz, and Contact pages remain part of the experience, while a new data lab lets visitors inspect the astronomy datasets supplied with the project.

DATA USED

Two supplied CSV datasets

Exoplanet catalogue: includes planet name, host star, discovery method and year, orbital period, radius, mass, and system distance where available.

Solar System physical parameters: includes object names and measurements such as radius, mass, density, rotation/orbital periods, gravity, and escape velocity where available.

Values and record counts are read from the project’s local CSV files. Missing values are displayed as unavailable rather than being replaced with zero.

TECHNOLOGY

How it is built

  • HTML, CSS, JavaScript — page structure, responsive glass UI, gallery, and quiz interactions.
  • Python + Flask — web routes, templates, form handling, and CSV downloads.
  • pandas + NumPy — data loading, filtering, cleaning, and numeric summaries.
  • Plotly — interactive charts for the data lab.
  • pytest — automated route and feature tests.
Scientific note: a radius/orbital-period filter is only a way to shortlist records for further study. It does not confirm that a world is habitable. The supplied exoplanet dataset does not include every factor needed to assess habitability, such as atmosphere or surface conditions.
